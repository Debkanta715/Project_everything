# Project Everything

A comprehensive collection of three modern web applications showcasing different technology stacks and use cases.

## 📁 Projects Overview

This repository contains three independent projects:

### 1. **Banking** - Simple Banking System
A Node.js and Express-based banking application with user authentication and account management.
- **Port:** 2001
- **Tech Stack:** Node.js, Express, MongoDB, JWT, bcrypt
- **Features:** User authentication, account management, email notifications

### 2. **Banking-Ledger** - Advanced Banking & Transaction System
A comprehensive banking system with ledger management, transaction tracking, and account operations.
- **Port:** 3000
- **Tech Stack:** Node.js, Express, MongoDB, JWT, bcrypt
- **Features:** Authentication, account management, transaction tracking, ledger system, token blacklist

### 3. **Food-Delivary-Webpage** - Food Delivery Landing Page
A modern, responsive food delivery website built with React and Vite.
- **Tech Stack:** React 19, Vite, Tailwind CSS, React Router
- **Features:** Hero section, feature showcase, responsive navbar, modern UI

## 🚀 Quick Start

### Prerequisites
- Node.js 14+ (for Banking projects)
- npm or yarn

### Installation & Running Each Project

**Banking Project:**
```bash
cd Banking
npm install
npm run dev    # Development with nodemon
# or
npm start      # Production
```

**Banking-Ledger Project:**
```bash
cd Banking_system/Banking-ledger
npm install
npm run dev    # Development with nodemon
# or
npm start      # Production
```

**Food Delivery Webpage:**
```bash
cd Food-Delivary-Webpage
npm install
npm run dev    # Development server
npm run build  # Production build
npm run lint   # Run ESLint
npm run preview # Preview production build
```
